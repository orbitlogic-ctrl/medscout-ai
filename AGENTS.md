# MedScout engineering instructions

- Write code, comments, tests, and docs in English. Explain changes and Python concepts to the user in Italian.
- Use Python 3.15 and the existing virtual environment. Type public interfaces, validate external inputs, and prefer the standard library.
- Stay within the approved milestone. Run pytest and record actual verification in docs/current-status.md.
- Keep catalog IDs stable and label fictional records with explicit provenance and verification status. Keep secrets, patient information, and private workspace files out of Git.
- Obtain explicit authorization before committing, pushing, or deploying.
